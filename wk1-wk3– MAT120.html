Five rules before you start

  • Functions use square brackets: Sin[x], not Sin(x).
  • Built-in names start with a capital letter: Plot, Sqrt, Pi.
  • Lists and ranges use curly braces: {x, 0, 4} means x from 0 to 4.
  • Powers use ^. Multiply with * or a space: 3 x is 3 times x.
  • Press Shift + Enter to run a cell.
